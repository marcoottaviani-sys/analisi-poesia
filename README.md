# analisi-poesia

Skill per Claude per l'analisi di testi poetici, basata sul framework di Marco Ottaviani (rev. 5).

## Cosa fa

Quando si incolla una poesia e si chiede di analizzarla, Claude applica il framework punto per punto:

0. Dominio di validità
1. Filosofia e topologia del soggetto
2. Come lavora il testo (figure e cancello della portanza)
3. Differenziale di densità
4. Suono e materialità
5. Risonanze
6. Livello operativo
7. Frizione alla lettura
8. Livello ontologico
9. Dispositivo patemico

L'analisi si chiude con un verdetto per assi (operativo, frizione, ontologico, patemico), mai con un voto unico.

## Come si installa

1. Scarica il file `analisi-poesia.zip` da questa pagina.
2. In Claude, apri la pagina delle skill e carica lo ZIP.
3. Incolla una poesia e chiedi di analizzarla.
